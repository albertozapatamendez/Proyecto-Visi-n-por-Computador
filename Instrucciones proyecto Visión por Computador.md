#### Instrucciones para la realización del proyecto

Se entregará una memoria del proyecto con temática abierta y se hará una exposición oral en clase de prácticas. Estos son los pasos a seguir para hacer el proyecto:

**1- Establecer el objetivo.** Ejemplos de cursos anteriores:

- Detección de señales de tráfico
- Identificación de cartas de la baraja española
- Detección de comida
- Extracción de números de matrículas
- Seguimiento en webcam de movimientos con una pelota para dibujar letras
- Detección de caminos en la UA
- Detección de peatones
- Búsqueda de plazas de aparcamiento
- Detector de fatiga facial
- Reconocimiento de caras (identificación)

**2- Búsqueda de datos etiquetados con la información deseada**, o creación de nuestra propia base de datos (esto es más complicado). Ejemplo de base de datos de señales de tráfico: [http://benchmark.ini.rub.de/?section=gtsrb&subsection=news](http://benchmark.ini.rub.de/?section=gtsrb&subsection=news) (Downloads), [enlace alternativo](https://www.kaggle.com/datasets/meowmeowmeowmeowmeow/gtsrb-german-traffic-sign). Consejo: Buscar en Google “image dataset” seguido de lo que queremos detectar, por ejemplo, “image dataset food”.

**3- Diseño o uso de técnicas existentes para resolver el problema.** El profesor os recomendará la metodología a seguir para empezar y también os irá asesorando durante las distintas etapas del proyecto.

**4- Evaluación del sistema propuesto.** El porcentaje de acierto obtenido como resultado puede ser mejor o peor (dependiendo de la dificultad del problema y de las técnicas empleadas), pero es importante que el método esté bien evaluado.
